# 批量操作范围红线（适用于所有仓库）

## 跨仓批量操作必须先确认范围

禁令/规范/迁移类指令默认只覆盖用户上下文里明确提到的活跃仓库，**绝不擅自扩到全组织/全账户/全私有仓**。

## 硬规则

1. 任何超过 3 个仓库的批量操作（开 PR、推分支、改文件、关 PR、删分支），必须先给用户一份确切的目标仓库清单（逐个列名），等用户明确点头后才动手。
2. 用户说「组织级」「全部」这类词时，仍要先列出会被波及的仓库总数与清单确认——数量本身可能就是用户没预料到的。
3. fork 仓与公开仓默认不在任何批量操作范围内，除非用户逐个点名。
4. 批量操作执行中每步只走 PR，禁止直推主线；出事故（推错分支/推错仓）立即冻结现场报用户裁决，不擅自回滚或强推。

## 教训

范围错觉的代价（数十个仓被误开 PR 再全部回滚）远大于确认清单的几分钟。宁可多问一次，不可多动一仓。
