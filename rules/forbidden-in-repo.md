# 禁止入库清单（适用于所有仓库）

按内容性质判断，不按路径/文件名/扩展名判断。以下一律禁止入库：

## 1. 过程性文档

- 计划文档：PLAN.md、plan-*.md、实施计划、roadmap 等
- 临时/一次性需求文档：REQUIREMENTS.md、需求.md、requirement-*.md（仓库规范化维护的 docs/PRD.md 除外）
- 实施/执行/分析报告：IMPLEMENTATION.md、实施记录、执行报告、分析、重构报告、audit-* 等
- AI 助手生成的过程性笔记（交流稿、思路记录、checklist 文档）

## 2. 验收证据

当轮验收运行证据一律禁止入库：原始日志、报告、trace、已填写或生成的 checklist、manifest、sidecar、实际读数、截图及其他图片/视频，包括截取、编码、改名、压缩或复制得到的版本；验收截图即使称为 golden 或基线也不能入库。

## 3. 二进制与大文件

jar、视频、大图片等二进制资产不入库。KB 级小图标/纹理等产品资产可以；JSON 文本形态的资产（如模型描述文件）可入但控制体积。

## 4. 密钥与隐私

密钥、令牌、密码、凭据、PII、内网地址、真实机器用户名等敏感内容——提交文件、提交消息、PR 标题与正文、合并总结、git 作者身份同样适用。

## 5. 本机绝对路径

仓库内用相对路径；外置目录用环境变量或 `<仓库根>` 等占位符。提交消息与 PR 正文同样禁止本机绝对路径。

## 6. AI 署名

禁止任何形式的 AI 签名或尾注：`Claude`、`Codex`、`Generated by ...`、`Co-authored-by: ...` 等；消息末尾不附作者署名/工具署名/生成来源标记。

## 7. 绕过手段

- 禁令适用于任何路径与载体：不得嵌入规格、源码、注释或资源，不得搬目录、重命名、换扩展名、压缩归档绕过
- 过程材料仅存被忽略的 `.tmp/` 或库外
- 禁止 `git add -f` 绕过忽略规则；已跟踪文件不会因新增 .gitignore 自动清理
- 禁止 `--no-verify`/`--no-gpg-sign` 跳 hooks

## 允许入库的例外

- 长期维护的产品文档：README.md、CHANGELOG.md、docs/API.md 等；模块自身对外 README
- 配置/规则类：rules 目录、AGENTS.md、CLAUDE.md
- 长期治理与规范文档：PRD、specs（不得夹带当轮运行结果）
- 静态用例与断言预期、自动化测试/验收源码、确定性输入夹具（预期必须独立定义，不得把本轮实际读数改称「期望」）
- 产品图片、图标、纹理等产品资产（不是验收截图）

## 误入库处理

- 提交前 `git status` 与 `git diff --cached` 完整审查
- 误暂存：`git reset HEAD <file>`；已误入库：单独提交一次 chore 移除
- 敏感内容已入库：追加删除只清当前版本；确需清历史须先获用户明确授权，推送用 `--force-with-lease`；泄露凭据还须撤销或轮换
