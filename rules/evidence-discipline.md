# 验收证据纪律（适用于所有仓库）

## 证据形态

- 禁止整局长录屏流水账：证据 = 分段短片段 + 逐条文字步骤描述（对标浏览器 e2e step），关键画面截图直接展示
- 每段证据必须标注验收的是什么功能（录屏叠加标注或清单逐条对应），让人工验收者一眼知道在看什么
- 数据断言自动判 PASS/FAIL（机器验收），人工只看视觉片段（人工验收）
- 证据逐条直接展示，禁止打包压缩包

## 证据去向

- 证据一律不入库、不进 PR 文件（见 forbidden-in-repo.md）；存 `.tmp/` 或以会话附件形式交付
- 入库的只有自动化流程源码与场景配置

## 可复跑要求

- 验收不是手工操作产物：场景起服/驱动/录制/断言/产物收集全自动化，任何机器可复测
- 外部依赖（ffmpeg/xvfb/服务包/运行时）环境变量注入，缺失时按 testing-and-assertions.md 的降级规则处理
- 测试须支持快速切入任意被测状态（状态注入/导演）与加速推进，只测目标功能不一镜到底
