# 文档同步规则（适用于所有仓库）

## 文档演进纪律

- PRD/需求登记：增量追加 + 状态更新，不重写历史
- 架构/API 文档：原地更新到当前真貌
- ADR（架构决策记录）：只追加不删除；推翻旧决策写新 ADR 并标记取代关系
- 文档同步与代码改动同 PR，不欠账

## 防漂移

- 代码不保存需求编号（除非仓库规则另有窄例外）；长期文档允许位置按各仓规则
- 发现入口文档（AGENTS.md/CLAUDE.md/README）过期：改文档，不要改代码去迁就文档
- 范围纪律：一个 PR 只做一件事，不夹带计划外能力或镀金

## 注释与语言

- 注释、提交信息、测试显示名一律简体中文（type/scope 英文小写）
- 默认不写注释，靠命名自解释；注释解释「为什么」而非复述「是什么」
